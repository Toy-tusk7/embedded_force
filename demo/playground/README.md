# EmbedForge Verify Playground

Firmware drivers written by NVIDIA Nemotron 3 Ultra (a TI TMP117 and a Bosch BMP388), verified against facts it
quoted from the manufacturers' datasheets. Plant a bug, or edit the code, and EmbedForge's verifier finds it: it runs
in your browser (Python through Pyodide) and calls no AI model.

Source, README and every Nemotron run: https://github.com/Toy-tusk7/embedded_force
