EmbedForge · Verify Playground

Plant a bug in a driver NVIDIA Nemotron wrote, and watch the datasheet catch it.

Both drivers were written by Nemotron 3 Ultra and verified against facts it quoted word for word from the manufacturer's datasheet. Pick a bug, or edit the code yourself, and press Verify: EmbedForge reads the C without running it, works out every byte it would send to the chip, and checks register fields, byte order, formulas and timing against those quotes. It runs here, in your browser.
